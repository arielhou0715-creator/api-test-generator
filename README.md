# api-test-generator

大模型 API 能力测评工具 —— 浏览器打开即用的在线版。

**在线地址：** https://arielhou0715-creator.github.io/api-test-generator/

## 是什么

一个单文件网页工具，用来快速验证任意大模型 API 的可用性：

- **对话**：连通性、鉴权、模型名、流式、多轮上下文、系统提示词、长度限制、停止序列等
- **图片生成**：文生图、指定尺寸、高清、批量、Base64 返回、图像编辑、图像变体
- **视频生成**：文生视频、图生视频、任务状态查询
- **向量**：单条 / 批量嵌入
- **性能**：延迟、并发、缓存命中、长文输出、上下文窗口探测

支持四种协议：**OpenAI 兼容**、**Anthropic Messages**、**Google Gemini 原生**、**平台聚合协议**（图片/视频/向量专用）。

## 历史记录

- **接口地址 / 模型名下拉**：点一下输入框，就能看到自己以前填过的地址和模型名，点一下直接回填，不用重复敲
- **历史测试记录**：每跑完一轮测试自动记一条（时间、地址、模型、协议、通过/失败/跳过各几项），点开可看当时每一项的明细
- 上限：地址与模型名各保留最近 10 条，测试记录保留最近 20 次；超出自动丢最旧的
- 数据只保存在你自己的浏览器里，**不含密钥**

## 使用方式

- **在线**：直接打开上面的在线地址
- **本地**：下载 `index.html`，双击用浏览器打开即可，无需安装任何东西

## 隐私说明

- 所有请求由**你的浏览器直接发送**到你填写的 API 地址，不经过任何第三方服务器
- 工具没有后端，不上传、不收集任何数据
- **密钥默认不保存在本地**；如需保存，需手动勾选「记住密钥」（仅存在你自己的浏览器里）
- 代码示例中密钥统一显示为 `YOUR_API_KEY` 占位符，不会写入真实密钥
- **历史记录只存在你自己的浏览器里**：接口地址、模型名的历史下拉，以及历次测试记录（时间/地址/模型/通过情况）都保存在本机浏览器缓存中，**不包含密钥**。点「忘记这些配置」清空配置与地址/模型历史；在历史记录面板点「清空历史记录」只清测试记录。

## 注意

本工具仅用于在你**有授权的测试账号**下验证接口可用性。部分测试（图片、视频、长文）会产生实际费用，运行前会弹窗确认。
